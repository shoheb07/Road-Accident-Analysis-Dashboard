# Road-Accident-Analysis-Dashboard
The Road Accident Analysis Dashboard is a data analytics and visualization project developed to analyze road accident data and identify accident patterns, causes, and trends.

# Road Accident Analysis Dashboard

## Project Overview

The Road Accident Analysis Dashboard analyzes accident datasets and visualizes accident trends, severity, and traffic safety patterns.

The project uses Python and data visualization techniques for analytics.


# Features

- Accident severity analysis
- Vehicle type distribution
- Trend visualization
- Dashboard analytics
- Traffic hotspot analysis


# Technologies Used

- Python
- Pandas
- Matplotlib
- Tableau / Power BI


# Installation

Install required libraries:

pip install pandas matplotlib


# Run Project

python road_accident_analysis.py


# Dashboard KPIs

- Total accidents
- Fatal accident percentage
- Vehicle distribution
- Monthly trends
